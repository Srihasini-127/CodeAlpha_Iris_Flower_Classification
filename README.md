# Iris Flower Classification

A machine learning project that classifies Iris flowers into Setosa, Versicolor, or Virginica using their sepal and petal measurements.

## Dataset

The dataset contains 150 flower records with these measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Model

A K-Nearest Neighbors (KNN) classifier was trained using scikit-learn. The data was split into training and test sets.

## Result

The model achieved 93.33% accuracy on the test set.
